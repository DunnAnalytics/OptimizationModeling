# Mixed-Integer Optimization Model

This project demonstrates advanced skills in mathematical modeling and prescriptive analytics using Python and Pyomo. Developed as part of graduate-level coursework in Business Analytics, it focuses on formulating and solving a real-world resource allocation and optimization problem.

## 📌 Overview

The solution pipeline involves:
- Loading and transforming structured data from Excel
- Writing data into a `.dat` file format for model ingestion
- Building an abstract optimization model using Pyomo
- Defining complex business constraints using mathematical logic
- Solving for cost minimization using binary and continuous decision variables

## 🧠 Skills Demonstrated

- **Data Preprocessing & Transformation**
  - Processed multi-sheet Excel input into model-ready `.dat` format using `pandas`
  - Structured and validated data for multi-indexed parameters

- **Optimization Modeling (Pyomo)**
  - Constructed an abstract model with multiple sets, parameters, decision variables, and constraints
  - Implemented advanced constraint logic, including:
    - Capacity thresholds
    - Demand fulfillment
    - Conditional binary constraints
    - Range bounds and resource limits

- **Prescriptive Analytics**
  - Formulated and solved a minimization problem
  - Applied integer programming techniques
  - Translated business requirements into mathematical constraints

- **Technical Stack**
  - Python 3
  - `pandas` for data manipulation
  - `pyomo` for modeling and optimization
  - Excel
